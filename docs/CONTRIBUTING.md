# Quy ước đóng góp

- Nhánh: `feature/<ten-ngan>` hoặc `fix/<ten-ngan>`.
- Commit: dùng động từ, mô tả một thay đổi chính; ví dụ `Add sequential dot product baseline`.
- Pull request: mô tả mục tiêu, cách kiểm thử và ảnh hưởng hiệu năng nếu có.
- Review: kiểm tra tính đúng đắn, checksum, xử lý lỗi MPI, race condition và khả năng tái lập benchmark.
- Không commit file build, dữ liệu cá nhân hoặc kết quả chưa được xác minh.
